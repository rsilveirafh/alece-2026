## Como usar

Cada página é **autocontida** — todo o CSS, JavaScript e os diagramas SVG estão embutidos no próprio arquivo. Não há dependência externa, então funciona offline: basta salvar o `.html` e abrir no navegador.

- **Tema claro e escuro** automáticos, conforme a preferência do sistema.
- **PDF:** `Ctrl+P` → Salvar como PDF. Os blocos recolhíveis (gabaritos, temas da discursiva) abrem sozinhos na impressão, então nada se perde.
- Funciona igual em computador e celular.

## Procedência do conteúdo

Os pesos por bloco de conteúdo são **estimativa** baseada na redação do Anexo II do edital e no padrão de provas recentes — não são distribuição oficial da banca.

As questões reais foram transcritas de provas públicas e estão creditadas dentro de cada página, com a banca, o ano e o órgão. Os simulados são autorais. Onde o gabarito oficial não pôde ser mapeado com segurança, isso está sinalizado no comentário da questão.
